# 通用 JSON 标注平台（本地网页）

一个模版驱动的通用标注工具：加载任意 `.json` / `.jsonl` 文件，自动解析所有 key 并推断合适的编辑控件，生成可编辑、可复现的**标注模版**；左侧为 case 列表，右侧为标注工作区。

## 运行

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .\.venv\Scripts\activate
pip install -r requirements.txt

# 三种指定数据文件的方式（任选其一）：
python server.py path/to/data.jsonl          # 1. 命令行参数
ANNOTATION_DATA_PATH=data.jsonl python server.py   # 2. 环境变量
python server.py                              # 3. 自动查找（见下）
```

浏览器打开：`http://127.0.0.1:5177/`

不显式指定文件时的自动查找顺序：

1. `output/` 下最新的 `*_edited*` 工作文件（继续上次的标注）
2. 项目目录下最新的 `.jsonl` / `.json` 文件（仓库自带 `sample_data.jsonl` 可用于体验）

## 输入格式

- `.jsonl`：每行一个 JSON 对象
- `.json`：单个对象，或对象数组

首次加载某个数据文件时，会扫描全部数据自动推断每个 key 的控件类型：

| 数据特征 | 推断控件 |
| --- | --- |
| 全为布尔值 | checkbox |
| 全为数字 | number |
| 少量不同取值的短字符串 | select（下拉，选项自动收集） |
| 长文本 / 含换行 | textarea（高度随文本长度） |
| 短字符串 | text |
| 对象 / 数组 / 混合类型 | json 编辑器 |

## 标注模版（可复现）

模版以文件形式保存在 `annotation_templates/<数据文件名>.template.json`，包含每个字段的完整配置。把该文件与数据一起归档/分发，即可在任何机器上复现同样的标注界面。

页面右上角"模版设置"可视化编辑：

- **标注边框大小**：textarea / json 控件的高度（行数）
- **是否可改**：`editable=false` 的字段渲染为只读，服务端也会拒绝写入
- **是否隐藏**：`hidden=true` 的字段不在工作区显示（数据仍保留）
- **存盘模式**：手动（点击"保存到文件"才写盘）或自动（每次修改后自动写入工作文件）
- **增删字段**：可在模版中增删/重排字段、改显示名、改控件类型、配置 select 选项
- **列表展示**：选择左侧列表的标题/副标题/标签字段

模版文件不合法时启动会自动重新生成；也可在模版设置中点"重新解析字段"基于当前数据重建。

## 标注操作

- 左侧：case 列表，支持关键词搜索、按"已修改/未修改"筛选、翻页、收起
- 右侧：按模版渲染当前记录的所有字段；可直接编辑值、删除 key、"+ 新增字段"添加新 key
- "保存此条"：写入服务端内存（自动存盘模式下修改会自动落盘，无需点击）
- 右上角"保存到文件"：把全部修改写入工作文件

## 输出

所有写盘均输出到 `output/<数据文件名>_edited.<后缀>`，**不覆盖原始文件**。重启后自动加载该工作文件，可继续上次的标注。
